Project Overview

The Intelligent Network Intrusion Detection System (INIDS) is an advanced machine‑learning‑driven security platform designed to detect, classify, and respond to malicious activity in network traffic.

INIDS demonstrates the practical application of multiple supervised learning models within a real‑time SOC‑oriented detection pipeline.

Key Capabilities

  • Multiple machine learning models (Random Forest, Gradient Boosting, Decision Tree, AdaBoost, MLP)
  • Binary and multi‑class intrusion classification
  • Real‑time prediction with confidence scoring
  • Unified SOC analytics dashboard
  • Batch and streaming inference pipelines
  • ROC curve analysis and feature importance visualization

Dataset

NSL‑KDD Dataset — an improved and cleaned version of the KDD’99 dataset commonly used in intrusion detection research.

It contains 125,973 training samples and 22,544 test samples with 41 extracted features, providing a balanced and realistic benchmark for evaluation.

Attack Categories

  • DoS — Denial of Service attacks
  • Probe — Surveillance and probing activity
  • R2L — Remote‑to‑Local attacks
  • U2R — User‑to‑Root privilege escalation

Technology Stack

Python, Scikit‑learn, Flask, Pandas, NumPy, Matplotlib, and a custom lightweight SOC‑style frontend architecture.
