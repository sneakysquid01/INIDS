Capture Overview

Live traffic capture is performed via a dedicated sensor process to collect raw network packets and forward them into the INIDS ingestion and analysis pipeline.

This interface provides operational context only. Packet capture is intentionally executed outside the web UI to preserve system integrity and security boundaries.

Capture Command

To initiate live traffic capture, execute the following command on the sensor host:

python src/capture_live_traffic.py
Note: Live packet capture requires elevated operating system privileges and direct access to network interfaces.

Operational Notes

  • Captured traffic is analyzed in near real‑time by the IDS engine
  • Allowlist and policy rules are applied during ingestion
  • Suspicious flows may generate alerts or prevention actions
  • Capture processes should run on dedicated sensor systems
