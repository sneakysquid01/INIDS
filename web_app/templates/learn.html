Training Mode

IDPS learns normal traffic patterns by establishing a dynamic baseline during an initial observation window (default: 72 hours). During this period all traffic is passively monitored without blocking.

  1. Observation — Collect flow statistics across all monitored interfaces.
  2. Feature extraction — Derive 78 statistical features per flow (packet rate, IAT, flags, payload entropy…).
  3. Baseline fitting — Fit Gaussian Mixture Model to benign distribution.
  4. Anomaly thresholding — Set per-feature alerting thresholds at μ ± 3σ.
  5. Continuous update — Baseline drifts with traffic; retrained nightly at 02:00 IST.
